# Evidence Docs

This directory stores documents that still carry evidence, lineage, provenance, or artifact context for the current branch.

Use these files when:

- tracing paper assets back to runs or source artifacts
- checking lineage or provenance
- recovering historical context that still affects current manuscript claims

Do not treat this directory as the main branch entrypoint. Use `AGENTS.md`, `README.md`, and `docs/governance/` first.
