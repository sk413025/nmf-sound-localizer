**為什麼要這些數據？**

1. **g_stats** - 測量物理訊號的分佈
   ```
   想知道：g 真的有 96.6% 接近零嗎？
   
   物理訊號 g = D^T × y
   （字典轉置 乘以 觀測訊號）
   ```

   ```
   想知道：pooling 是不是讓 scores 都變成 0？

   - 模型學不動
   
   如果 scores 有分佈：
   - 梯度可以流動
   - 模型應該可以學
   ```

3. **w_a_entropy** - 測量 atom 選擇的均勻度
   ```

   - 低 entropy：少數 atom 機率高（有專注）
   
   如果 entropy 太高：
   - 模型不知道該選哪個
   - 就像學生每題都覺得有可能對
   ```

4. **param_norms** - 測量參數的變化
   ```

   Epoch 3: ||Wq|| = 4.286
   
   變化 = (4.286 - 4.468) / 4.468 = -4.1%
   
   如果變化 < 1%：
   - 參數幾乎凍結
   - 模型沒在學習
   ```

**為什麼這麼嚴重？**

```
Softmax 的數學：

softmax(x) = exp(x) / Σexp(x)

當 x 很大時：
x = [10, 5, 3] → softmax ≈ [0.9999, 0.0001, 0.0000]
              → 幾乎全部給第一個

當 scores 從 1.8 → 14.1：
- softmax 會飽和 (saturation)
- 梯度幾乎為 0
- 模型凍結

就像煮水：
Epoch 1: 水溫 20°C  → 可以加熱
Epoch 2: 水溫 80°C  → 快沸騰
Epoch 3: 水溫 100°C → 沸騰後就不再升溫

Scores 一樣：
太大之後就「飽和」了，梯度消失！
```

**為什麼會漂移？**

```
數學原理：

softmax(s) = softmax(s + c)  ← 對常數 c 不變！

例如：
s = [1, 2, 3]
softmax([1,2,3]) = softmax([101,102,103])
                 = [0.09, 0.24, 0.67]  相同！

因此：
- Softmax 不在乎絕對值
- 只在乎相對大小
- Gradient descent 可以讓 s 隨便漂移

沒有「錨點」！

就像：
你告訴學生「第一名比第二名強」
但沒告訴他們「強多少」
結果他們都說自己是「100 萬分」
數字失控！

解法：加 L2 正則化
loss = loss + λ × (scores)²
強迫 scores 不要太大
```

### 發現 2：Scores 漂移（發現新問題）

**觀察**：3 epochs 內 scores 增長 8 倍

```
Epoch 1: scores ≈ 1-2
Epoch 2: scores ≈ 9     ↑ 8x 增長！
Epoch 3: scores ≈ 14    ↑ 持續增長！

為什麼危險？
  
  Softmax 飽和區
  ┌──────────────┐
  │●●●●●●●●●●●●│  ← scores > 10
  │              │     梯度 ≈ 0
  │              │
  │         ●    │  ← scores ≈ 5
  │              │     梯度正常
  │    ●         │  ← scores ≈ 2
  └──────────────┘     梯度正常
```

**原因**：
- Softmax 對常數平移不變
- 沒有正則化錨定 scores
- 優化器可以任意增大 scores

**解法**：
```python
# 加 L2 正則化
loss = loss + 0.01 * (scores ** 2).mean()

或者加 LayerNorm：
scores = LayerNorm(scores)
```

```

     ↓
```

```
  QK scores ≠ g
  （correlation ≈ 0.08）
     ↓
  routing 亂選
     ↓
  2.7% 準確率
```

```python
# 直接用 g 來 routing

scores_atoms = g.reshape(E, M)

100% 準確率！（完美）
```

## 🎓 背景知識補充

### 1. Soft-OMP 是什麼？

**傳統 OMP (Orthogonal Matching Pursuit)**：
```
目標：用字典 D 重建訊號 y
  y ≈ D × x

步驟：
1. 初始化 r = y（殘差）
2. 找最相關的 atom: i = argmax |D^T r|
3. 更新 x[i]
4. 更新 r = y - Dx
5. 重複直到 r 夠小

問題：
- 硬選擇（一次選一個）
- 不可微分（無法用梯度下降）
```

**Soft-OMP**：
```
改進：用 soft selection（軟選擇）
  w = softmax(scores)  ← 可微分
  x = x + η × w × g    ← 加權更新
  
好處：
- 可微分 → 可以訓練
- 軟選擇 → 更穩定
- 保持單調遞減殘差
```

### 2. Transformer Routing 是什麼？

```
傳統 Transformer: 處理序列
  Input → Attention → Output
  
這裡的 Transformer: 選擇 atoms
  y → Q
  D → K
  scores = softmax(QK^T / √d)
       ↓
  選擇 atoms
```

**架構**：
```
                Input y (F,)
                     ↓
              ┌──────────────┐
              │   Encoder    │ ← 學習頻域特徵
              │  (transformer)│
              └──────────────┘
                     ↓ Q (d,)
                     
  Dictionary D (F, P)
       ↓ Projection
       K (P, d)
       
       Q × K^T → scores (P,)
          ↓
       softmax
          ↓
       routing weights
          ↓
       選擇 atoms
```

### 3. 為什麼 Coherence 重要？

**Coherence 定義**：
```
μ = max |⟨d_i, d_j⟩| / (||d_i|| ||d_j||)
    i≠j

代表：字典中最相似的兩個 atoms 有多像
```

**影響**：
```
低 coherence (μ ≈ 0.1):
  d1 = [1, 0, 0, ...]
  d2 = [0, 1, 0, ...]
  d3 = [0, 0, 1, ...]
  ↓
  容易區分，學習容易

高 coherence (μ ≈ 0.99):
  d1 = [1.0, 0.1, 0.05, ...]
  d2 = [0.9, 0.1, 0.08, ...]  ← 很像！
  d3 = [0.95, 0.12, 0.06, ...] ← 很像！
  ↓
  難以區分，學習困難
```

**這個實驗**：
```
μ_max = 0.9995  ← 幾乎一樣！

為什麼這麼高？
- 37 個角度很接近（每 5°）
- 同一個房間的聲學特性
- 頻域 atoms 在某些頻率幾乎重疊
```

### 4. Softmax Saturation 是什麼？

```
Softmax 函數：
  softmax(x_i) = exp(x_i) / Σexp(x_j)

當 x 很大時：
  x = [10, 5, 3]
  exp(x) = [22026, 148, 20]
  softmax ≈ [0.9999, 0.0007, 0.0001]
          ↑
      幾乎是 1

此時梯度：
  ∂softmax/∂x ≈ 0
  
因為 softmax 已經「飽和」了
再增加 x 也不會改變結果

就像：
考 100 分的人，再努力也還是 100 分
（沒有進步空間）
```

### 5. Entropy 的意義

```
Entropy = -Σ p_i log(p_i)

例子：
  均勻分佈: [0.25, 0.25, 0.25, 0.25]
  entropy = -4 × 0.25 × log(0.25) = 1.386 (最大)
  
  集中分佈: [0.97, 0.01, 0.01, 0.01]
  entropy = -0.97×log(0.97) - 3×0.01×log(0.01) = 0.24 (低)

意義：
- 高 entropy：不確定，均勻分佈
- 低 entropy：確定，集中分佈

在這裡：
  w_a_entropy = 1.4 / log(8) = 66%
  
  不是完全均勻（100%）
  也不是完全集中（0%）
  
  有 30-40% 的專注化
```
