# Role Packet: Governance and Red-Team Agent

## Objective

Challenge the other specialist reports and identify where the proposed improvements would add ceremony, ambiguity, or duplicated structure without improving Codex-assisted manuscript work.

## Required inputs

- `docs/codex-native-assessment/CODEX_CAPABILITY_BASELINE.md`
- `docs/codex-native-assessment/SHARED_RUBRIC.md`
- all accepted specialist reports from the first review round

## Focus

- overengineering risk
- role overlap
- context inflation
- failure modes in multi-agent coordination
- mismatch between proposed process and actual Codex capabilities

## Questions to answer

- Which recommendations are too abstract to execute?
- Which recommendations duplicate existing `AGENTS.md`, skill, or script functionality?
- Which proposals would make the branch more bureaucratic without making it more Codex-native?
- What is the minimum viable governance model?

## Required outputs

- a red-team critique of the accepted reports
- simplification recommendations
- a failure-mode register
- a minimal governance model for future implementation agents

## Failure conditions

Your report should be considered weak if it rejects recommendations without proposing a simpler alternative or if it ignores the Phase 0 capability baseline.
