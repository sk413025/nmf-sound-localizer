# Specialist Report Template

Use this template for every specialist assessment report.

## 1. Objective

State the assigned role and the question the report is trying to answer.

## 2. Codex baseline assumptions used

List the capability-baseline items that shaped the assessment.

## 3. What was inspected

List the repository files, scripts, or commands inspected.

## 4. Findings

For each finding:

- `Finding`
- `Evidence`
- `Why it matters for Codex-native manuscript work`

## 5. Scores against the shared rubric

Score all categories from `docs/codex-native-assessment/SHARED_RUBRIC.md`.

## 6. Recommendations

For each recommendation:

- `Change`
- `Why this uses Codex better`
- `Why this helps manuscript work`
- `Priority`: `P0`, `P1`, or `P2`

## 7. Acceptance criteria

State how a follow-on implementation agent would know the recommendation is done.

## 8. Risks if not fixed

List the operational or manuscript-quality risks of leaving the current state unchanged.

## 9. Quick wins

List 3 low-cost improvements.

## 10. Structural changes

List 3 deeper changes requiring coordinated implementation.

## 11. Blockers

List blockers that cannot be resolved from local inspection alone.

## 12. Confidence level

Choose one: `high`, `medium`, `low`
