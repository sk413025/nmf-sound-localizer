# Task Packet: Results Interpretation

## Objective

Translate executed results into contract-compliant analysis and manuscript-supporting interpretation.

## Source-of-truth files

- run logs and metrics under `results/`
- `docs/governance/experiment-contract.md`
- `AGENTS.md`

## Required skill

- `results-interpretation`

## Role

- `results-interpreter`

## Non-goals

- fabricating metrics
- treating unexecuted code as evidence

## Required outputs

- key numbers
- interpretation
- success and failure analysis
- follow-up recommendations

## Acceptance criteria

- analysis is grounded in actual run artifacts
- language matches experiment contract expectations

## Escalation conditions

- metrics and logs disagree
- required artifacts are missing

## Handoff target

- `manuscript-reviser` or `supervisor`
