# Task Packet: Submission Readiness

## Objective

Assess whether a manuscript-facing asset set is ready for Nature Communications submission work.

## Source-of-truth files

- `paper/`
- `docs/nature-communications/nature-communications-submission-requirements.md`
- `docs/governance/submission-contract.md`

## Required skill

- `nature-communications-submission`

## Role

- `submission-auditor`

## Non-goals

- changing manuscript claims
- bypassing asset review for main-paper figures

## Required outputs

- compliance gaps
- packaging risks
- required follow-up actions

## Acceptance criteria

- issues are tied to canonical requirements
- next owner is clear for each follow-up

## Escalation conditions

- main-paper vs supplementary boundary is unclear
- submission-critical metadata is missing

## Handoff target

- `paper-asset-reviewer` or `supervisor`
