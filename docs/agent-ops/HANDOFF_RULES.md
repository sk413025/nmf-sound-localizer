# Handoff Rules

Use these rules whenever work moves from one role to another.

## Required handoff content

Every handoff must state:

- objective
- source-of-truth files used
- what was changed or concluded
- what remains unresolved
- explicit next role
- acceptance criteria for the receiver

## Default handoff paths

- claim-auditor -> manuscript-reviser
- results-interpreter -> manuscript-reviser
- manuscript-reviser -> reviewer or supervisor
- submission-auditor -> paper-asset-reviewer or supervisor
- any specialist -> red-team-reviewer when the work adds complexity or changes process

## Do not hand off like this

- "someone should check this"
- "probably fine"
- "needs polishing"

A valid handoff names the next role and what that role must decide.

## Escalate instead of handing off when

- the evidence is contradictory
- a claim change could alter the paper's interpretation
- no current role cleanly owns the remaining decision
