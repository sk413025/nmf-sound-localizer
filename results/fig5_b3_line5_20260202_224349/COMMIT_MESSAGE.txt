Results: Fig5 B3 — 5 band-wise comparison line plots (QK vs PHYSICS; True DoA) with equivalence-preserving decomposition

Background
- Fig5 panel B3 (v1/v3) is a single-sample comparison between:
  - PHYSICS baseline: `g_energy_expert` (OMP-style |D^T y| aggregated by expert)
  - Model-native routing: `scores_expert` (Transformer QK routing pooled by expert)
- In v9/v10, “banded” visualizations changed the green curve into a projection-based proxy (derived from `D^T y` and `scores_atoms`), which breaks equivalence to the original B3 semantics and explains the v3↔v10 QK mismatch documented in `figure5_b3_v3_vs_v10_report.md`.

Motivation
- We want to compare QK vs PHYSICS across frequency bands, but without redefining the underlying quantities.
- We also want a clean visual comparison per band (one plot per band) instead of a polar plot.

Purpose
- Produce an equivalence-preserving band decomposition (physics sign-aligned; QK via Integrated Gradients) and render 5 comparison line plots:
  - Full band (300–3000 Hz)
  - 300–500, 500–1000, 1000–2000, 2000–3000 Hz
- Each plot overlays QK, PHYSICS, and the True DoA marker so we can visually judge band-wise “which method peaks at the truth”.

Important note (y-axis scale mismatch)
- Raw PHYSICS and QK scores have different numeric ranges and can be signed (QK + IG contributions; physics sign-aligned contributions).
- For visual comparability we use **per-curve min-max normalization** in each plot (`--compare_norm per_curve_minmax`).
  - This preserves each curve’s argmax (peak angle) BECAUSE it is a monotone transform.
  - This is visualization-only; all numeric equivalence checks are performed on raw values.

Cross-experiment analysis (≥3 commits; causal patterns)
- v3/v4/v6 B3 (commits 0590b12, b8e1148, c0cb7eb) preserve the original semantics by plotting `scores_expert` directly, so “QK vs OMP” is a model-native vs physics comparison.
- v9 introduced per-frequency proxy scoring (commit 58118bf) which is useful for mechanism exploration, BUT it changes the green curve’s meaning BECAUSE it replaces model-native QK with a projection-weighted surrogate.
- This run preserves the original semantics while enabling band-wise comparison via equivalence-preserving decomposition.

Extracted principles
- If the target uses a nonlinearity like `abs()`, do not apply it per-band and sum; use a decomposition that is consistent with the full-band nonlinearity (here: sign-aligned contributions).
- If the target is a non-linear model output (Transformer), band-wise views must be attribution (IG/grad-based) or they become proxies; label them explicitly.
- For band-wise visual comparison of two curves with different numeric ranges, per-curve monotone normalization is acceptable for “peak angle / shape” comparison, but it does not support amplitude comparison.
