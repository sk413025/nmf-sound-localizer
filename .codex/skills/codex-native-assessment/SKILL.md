# Codex Native Assessment

Use this skill when the task is about:

- whether the branch is more `codex-native` or `agent-native`
- how to improve Codex collaboration on manuscript work
- multi-agent readiness for paper writing, evidence tracking, or submission preparation
- evaluating `AGENTS.md`, local skills, onboarding docs, or manuscript-facing automation

## Required first step

Open and follow:

- `START_HERE_AGENT.md`
- `docs/codex-native-assessment/README.md`
- `docs/codex-native-assessment/CODEX_CAPABILITY_BASELINE.md`
- `docs/governance/codex-collaboration-contract.md`

Treat the capability baseline as the starting point for the term `codex-native`.

## Workflow

1. Confirm the task is manuscript-first rather than figure-first.
2. Read the shared rubric in `docs/codex-native-assessment/SHARED_RUBRIC.md`.
3. If acting as supervisor, use `docs/codex-native-assessment/SUPERVISOR_PLAYBOOK.md`.
4. If acting as a specialist, use the matching role packet under `docs/codex-native-assessment/roles/`.
5. Write findings using `docs/codex-native-assessment/REPORT_TEMPLATE.md`.

## Guardrails

- Do not define `codex-native` purely from repository preference; ground it in the capability baseline.
- Do not treat figure generation as the primary goal of this branch.
- Prefer extending existing repository primitives such as `AGENTS.md`, local skills, and `scripts/paper/` over inventing parallel systems.
- If the user asks for the latest Codex product behavior, refresh the local CLI facts and verify with official OpenAI Codex sources before finalizing conclusions.
