# Data Availability Statement

All data supporting the findings of this study are available within the paper
and its Supplementary Information files. The experimental results, model
checkpoints, and analysis outputs are available in the project's Git repository
at [URL] with Git LFS tracking for large files.

Raw audio datasets are available from the corresponding author upon reasonable
request due to their large size (>50GB). Processed datasets and experimental
configurations are provided as Git LFS objects with SHA256 hashes for verification.

## Specific Data Artifacts

- **Experiment results**: Git repository at [URL], `results/` directory
- **Model checkpoints**: Tracked with Git LFS, commit hashes provided in Methods
- **Analysis scripts**: `scripts/` directory in repository
- **Ablation study data**: Git commit b9dcafa
- **Master figure generation**: Git commit 872aa65

Data lineage is fully documented through git commit history with experiment
tracking per project guidelines.
