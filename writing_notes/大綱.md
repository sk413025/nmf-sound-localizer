# Nature Communications 論文大綱

## 核心訊息
**一句話總結**: 我們證明物理與學習的協同對於聲學定位是必要的，單獨任一者都無法有效工作。

## 結構

### Abstract (150 words)
- [ ] 背景 (1-2 句)
- [ ] 方法創新 (2-3 句)
- [ ] 關鍵結果 (2-3 句 + 數字)
- [ ] 影響 (1 句)

### Introduction (~1,500 words)
- [ ] 問題背景
- [ ] 現有方法的限制
- [ ] 我們的創新
- [ ] 論文組織

### Results (~2,500 words)
- [ ] 系統架構與核心表現 (93.5%)
- [ ] 消融實驗: 機制歸因
  - [ ] 物理-學習協同是必要的
  - [ ] 稀疏性是根本的
  - [ ] Transformer 實現特徵學習
- [ ] SNR 穩健性
- [ ] 路由分析

### Discussion (~1,200 words)
- [ ] 結果詮釋
- [ ] 與相關工作比較
- [ ] 限制與未來方向
- [ ] 更廣泛的影響

### Methods (~3,000 words)
