## 第一部分：時間反轉聲學 [R1] & [R4]

### 1.1 核心發現：波動方程的時間反轉對稱性

Mathias Fink 在 1996 年的這篇經典論文 [R1] 提出了一個看似簡單但深刻的觀察：**聲波方程在時間反轉下是對稱的**。

讓我用數學來說明這件事。聲波在介質中傳播遵循波動方程：

```
波動方程：
                    1   ∂²p
            ∇²p  -  ── ──── = 0
                    c²  ∂t²

其中：
  p(x,t) = 聲壓場（空間位置 x，時間 t）
  c = 聲速
  ∇² = 拉普拉斯算子（空間的二階微分）
```

現在關鍵來了：如果我們把 `t` 換成 `-t`，方程會變成什麼？

```
把 t → -t 代入：

                    1   ∂²p
            ∇²p  -  ── ──────── = 0
                    c²  ∂(-t)²

因為 (-t)² = t²，所以：

                    1   ∂²p
            ∇²p  -  ── ──── = 0   ← 完全一樣！
                    c²  ∂t²
```

**這個數學對稱性的物理意義是什麼？**

如果 `p(x,t)` 是波動方程的一個解（比如聲波從 A 點傳到 B 點），那麼 `p(x,-t)` 也是一個解（聲波從 B 點傳回 A 點）。換句話說，**把聲波的時間軸反轉，得到的仍然是一個合法的聲波傳播過程**。

### 1.2 時間反轉鏡的實驗實現

理論是美好的，但如何在實驗室裡實現「時間反轉」呢？Fink 的團隊發明了「時間反轉鏡」（Time-Reversal Mirror, TRM）：

```
時間反轉鏡實驗的三個步驟：

步驟 1：發射（Emission）
┌─────────────────────────────────────────────────┐
│                                                 │
│    聲源 ●────→ 散射介質 ────→ ▮▮▮ 換能器陣列    │
│         發出脈衝   （複雜障礙物）   記錄訊號 s(t)  │
│                                                 │
└─────────────────────────────────────────────────┘

步驟 2：時間反轉（Time Reversal）
┌─────────────────────────────────────────────────┐
│                                                 │
│    電腦處理：把記錄的訊號 s(t) 反轉成 s(T-t)     │
│    （T 是總記錄時間）                            │
│                                                 │
└─────────────────────────────────────────────────┘

步驟 3：回放（Re-emission）
┌─────────────────────────────────────────────────┐
│                                                 │
│    聲源 ●←────  散射介質 ←──── ▮▮▮ 換能器陣列    │
│    自動聚焦！   （相同障礙物）    發射 s(T-t)     │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 1.3 驚人的實驗結果：散射變成了「幫手」

傳統觀點認為散射是「敵人」——它把乾淨的訊號攪成一團漿糊。但 Fink 的實驗發現了一個反直覺的現象：

```
傳統聚焦 vs 時間反轉聚焦：

【均勻介質中】
                        聚焦點大小 ≈ λL/a
    ●                   （λ = 波長，L = 距離，a = 陣列孔徑）
   ╱│╲
  ╱ │ ╲                 受限於衍射極限
 ╱  │  ╲
▮▮▮▮▮▮▮ (TRM)

【複雜散射介質中】
                        聚焦點大小 << λL/a
    ●                 
   ╱│╲╲╱│              超越衍射極限！
  ╱╲│╲╱│╲              （超解析度現象）
 ╱╲╲│╱╲│╱╲
▮▮▮▮▮▮▮ (TRM)
   ↑
 散射體讓聲波走更多路徑
 → 等效於「擴大」了陣列孔徑
```

**為什麼散射反而有幫助？**

想像你站在一個充滿柱子的大廳裡喊一聲。聲波會撞到各個柱子，產生多重反射。這些反射波會從各種不同的角度到達接收器。當你把這些訊號時間反轉後再播出去，**每一條反射路徑都會被「逆行」**，所有的能量最終都匯聚回原點。

散射體就像是在你和接收器之間放了很多「虛擬換能器」——它們把聲波轉向，讓原本只能從正面「看到」聲源的接收器，現在可以從各個角度「看到」聲源。這等效於擴大了接收器的孔徑，因此提高了聚焦的解析度。

### 1.4 [R4] 的擴展：時間反轉聲學的綜合回顧（2008）

[R4] 是對時間反轉聲學領域的綜合回顧，總結了從 1996 年到 2008 年的發展。它補充了幾個重要的理論和應用進展：

**時間反轉算子（Time-Reversal Operator）**：

當你有一個換能器陣列在多目標環境中操作時，可以定義一個「時間反轉算子」K\*K。這個算子的特徵向量對應於場景中的不同散射體。這個概念後來被用於選擇性聚焦——你可以選擇只聚焦在最強的目標上，或者依次聚焦在不同目標上。

```
時間反轉算子的物理意義：

傳輸矩陣 K：
  K_{ij} = 從第 j 個換能器發射，在第 i 個換能器接收的響應

時間反轉算子 K*K：
  - 厄米特矩陣（Hermitian）→ 特徵值都是實數
  - 每個非零特徵值對應一個散射體
  - 特徵向量 = 聚焦到該散射體的最佳發射波形

             ┌──────────────┐
 目標 1 ●    │              │
             │   K*K        │  → 特徵值 λ₁, λ₂, λ₃
 目標 2 ●────│   特徵分解    │  → 特徵向量 v₁, v₂, v₃
             │              │     （對應三個目標的聚焦波形）
 目標 3 ●    └──────────────┘
```

**混沌腔體中的時間反轉**：

Fink 的團隊還在「混沌腔體」（如不規則形狀的矽晶片）中做了時間反轉實驗。在這種環境中，聲波會經歷無數次反射，最終填滿整個腔體。令人驚訝的是，即使只用一個換能器，只要錄音時間夠長，時間反轉仍然可以精確聚焦！這是因為混沌腔體的「遍歷性」（ergodicity）讓單一換能器可以「收集」到來自所有方向的資訊。

## 第二部分：逆散射問題的數學基礎 [R5] & [R6]

### 2.1 什麼是「逆散射問題」？

[R5] 和 [R6] 處理的是一個更抽象但更基礎的問題：**如果我們只能測量「散射場」，能不能反推出散射體的形狀或位置？**

```
正問題（Forward Problem）vs 逆問題（Inverse Problem）：

【正問題】已知原因，求結果
  
    已知：聲源位置、散射體形狀、介質特性
    求解：各處的聲場分佈
  
    這是「物理模擬」→ 通常是良態（well-posed）問題

【逆問題】已知結果，求原因
  
    已知：在某些位置測量到的散射場
    求解：散射體的形狀或位置
  
    這是「反演」→ 通常是病態（ill-posed）問題
```

### 2.2 [R5] 的核心貢獻：有限孔徑問題的最佳化方法

[R5]（1989 年發表於 Inverse Problems）討論的是一個實際的限制：**你不可能在散射體周圍的所有方向都放置感測器**。這種「有限孔徑」（limited aperture）的情況會讓逆問題變得更加困難。

**數學框架：**

在聲學逆散射中，我們通常測量的是「遠場模式」（far-field pattern），它描述了當觀測距離趨近無窮大時，散射場的角度分佈。數學上，這可以寫成：

```
遠場模式 u_∞(θ) 與散射體邊界 ∂D 的關係：

    u_∞(θ) = ∫∫_∂D G(θ,x) φ(x) dS(x)

其中：
  θ = 觀測方向
  G(θ,x) = Green 函數（波從 x 傳播到方向 θ 的響應）
  φ(x) = 散射體邊界上的場值
  ∂D = 散射體邊界

逆問題：從 u_∞(θ) 反推 ∂D 的形狀
```

**有限孔徑的困難：**

如果你只能測量某些方向的遠場模式（比如只有 θ ∈ [0°, 90°] 而不是 [0°, 360°]），你就失去了一部分資訊。這讓逆問題變得「欠定」（underdetermined）——有無窮多個散射體形狀可以產生相同的有限孔徑測量。

[R5] 提出用「最佳化方法」來處理這個問題：定義一個「失配函數」（misfit function）來衡量「預測的遠場」與「測量的遠場」之間的差異，然後最小化這個失配函數。

```
最佳化框架：

    min_∂D  J(∂D)  =  ∫_Ω | u_∞^predicted(θ; ∂D) - u_∞^measured(θ) |² dθ
  
    Ω = 可測量的角度範圍（孔徑）
  
問題：這個最佳化問題有多個局部最小值
     → 需要好的初始猜測
     → 需要正則化來穩定解
```

### 2.3 [R6] 的核心貢獻：小障礙物展開法

[R6]（2008 年發表於 Inverse Problems）提出了一個更精緻的方法來處理「小」散射體的情況。當散射體的尺寸遠小於波長時，可以用一種「漸近展開」來簡化問題。

**物理直覺：**

想像一個非常小的石子掉入水中。它產生的漣漪在遠處看起來就像是來自一個「點源」。同樣地，當聲波遇到一個很小的障礙物時，散射場在遠處也可以近似為來自一個等效的「點散射體」。

**數學框架：**

```
小障礙物的漸近展開：

當散射體尺寸 ε → 0 時：

    u_∞(θ) ≈ ε^d · A(θ) + O(ε^(d+1))
  
其中：
  d = 空間維度
  A(θ) = 取決於散射體位置和形狀的「散射振幅」

失配函數的泰勒展開：

    J(∂D) = J₀ + ε·J₁ + ε²·J₂ + ...
  
    J₁ 可以用 topological derivative 表示
    → 告訴你「在哪裡放一個小障礙物會最大程度改變失配函數」
```

**拓撲導數（Topological Derivative）**：

這是 [R6] 的核心概念。拓撲導數告訴你：如果你在空間中某個點放入一個無窮小的障礙物，失配函數會如何變化。

```
拓撲導數的應用：

1. 計算整個空間的拓撲導數場 T(x)
2. T(x) 最負的地方 = 最可能存在散射體的位置
3. 在那裡放入一個小障礙物作為初始猜測
4. 用標準最佳化方法精化形狀

這提供了一種「無需初始猜測」的逆散射方法
```

### 2.4 為什麼逆散射問題是「病態」的？

[R5] 和 [R6] 都強調了逆散射問題的「病態性」。讓我用一個簡單的例子來說明這是什麼意思。

**病態問題的三個特徵（違反 Hadamard 條件）：**

```
Hadamard 良態問題的三個條件：

1. 存在性：解必須存在
2. 唯一性：解必須唯一
3. 穩定性：解必須連續依賴於數據

逆散射問題通常違反第三個條件！

例子：SVD 分析

假設逆問題可以寫成 Ax = b，其中 A 的奇異值分解是：

    A = U Σ V^T
  
    Σ = diag(σ₁, σ₂, σ₃, ...)
  
對於逆散射問題，奇異值會快速衰減：

    σ₁ >> σ₂ >> σ₃ >> ...

這意味著：

    x = V Σ⁻¹ U^T b = Σᵢ (uᵢ^T b / σᵢ) vᵢ
  
    ↑ 當 σᵢ 很小時，即使 b 有微小誤差，
      (uᵢ^T b / σᵢ) 這一項會被放大到爆炸！
```

**視覺化病態性：**

```
測量誤差如何被放大：

輸入誤差 δb        輸出誤差 δx
   │                  │
   │  σᵢ 很大         │  → δx 很小（穩定）
   │                  │
   │  σᵢ 很小         │  → δx 很大（不穩定）
   │                  │
   │  σᵢ ≈ 0          │  → δx → ∞（爆炸！）
   ▼                  ▼

解決方法：正則化（Regularization）

1. 截斷 SVD：只保留較大的奇異值
2. Tikhonov 正則化：加入 ||x||² 懲罰項
3. 迭代正則化：用早停（early stopping）控制解的複雜度
```
