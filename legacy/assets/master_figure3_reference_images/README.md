## Master Figure 3 Reference Images

This directory quarantines legacy reference images used during the
`Master Figure 3` lineage reconstruction and panel-first manuscript
recomposition work.

Contents:

- `Figure-1.jpg` through `Figure-6.jpg` / `Figure-5.png`: historical
  legacy figure exports preserved for lineage tracing only.
- `master_figure3_reference_screenshot_1.png`
- `master_figure3_reference_screenshot_2.png`
  Local screenshot captures used during visual comparison and panel
  remapping audits.

These files are not canonical manuscript assets and must not be used as
active paper-facing figure sources. Canonical current figures remain under
`paper/figures/`, with active panel assets and manifests under
`figures/output/`.
