# Legacy Figure Quarantine

This directory holds figure-related code and assets that were removed from the
active six-figure manuscript workflow but are being retained temporarily for
history, traceback, or fallback inspection.

Contents here are intentionally outside the active paper contract.

- `generators/`: retired figure generators that should no longer be discovered
  or run by the active pipeline
- `output/`: retired upstream PDFs, panel manifests, and support assets that
  should no longer live under `figures/output/`
- `paper_assets/`: retired manuscript-era figure assets that should no longer
  live under `paper/figures/`

Do not treat anything in this directory as current manuscript authority.
